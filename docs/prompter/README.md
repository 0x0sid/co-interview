# Inherited Prompter reference

Neverblank was forked from Prompter, a voice-following teleprompter, on 2026-09-15. Its matching
engine, reader, scrolling and design system were reused, and code comments in `prompter/Matching/`,
`prompter/Prompt/` and `prompter/DesignSystem/` cite these documents for the reasoning behind them.

| Document | What it explains |
| --- | --- |
| [`MATCHING_ENGINE.md`](MATCHING_ENGINE.md) | Speech-to-text matching, thresholds, tokenization, scroll ownership |
| [`DECISIONS.md`](DECISIONS.md) | Prompter's dated decisions with their evidence |
| [`ARCHITECTURE.md`](ARCHITECTURE.md) | Prompter's module structure |
| [`BUILD_SPEC.md`](BUILD_SPEC.md) | Prompter's original product specification |

Product, roadmap and release statements in these files are Prompter's, not Neverblank's.
